## 1. 项目概述

元租房是元梦空间内的虚拟空间租赁业务：平台将建筑（楼栋/空间组）拆分为房间对外出租，用户下单租用并占用房间，支持个人与商业两类租约。

核心数据链：建筑配置（tan_core_group_part，楼栋/房间容量）→ 租房订单（tan_core_rent_order，8.8 万单）→ 房间租约记录（tan_core_rent_room，房间级状态）。

## 2. 涉及数据表

| 表名 | 用途 | 备注 |
|------|------|------|
| tan_core_group_part | 元租房建筑配置表 | 主键 id（即「楼栋 id」）；时间字段 created_at |
| tan_core_rent_order | 租房订单表 | 主键 order_id；时间字段 created_at |

## 3. 字段口径说明

### tan_core_group_part（建筑配置表）

- 主键 id 即「楼栋 id」（rent_order / rent_room 的 group_part_id 指向它，已验证 98%+ 命中）
- scene_type：绑定建筑场景类别，枚举见表注释（**4=公租房**）；is_rent：是否可租（见表注释）
- **room_num（房间总数）与 rent_num（已出租数快照）**：rent_num 是快照汇总值，**实时出租数以 rent_room.status=1 为准**
- building_no / building_name / core_addr：楼栋编号 / 建筑名称 / 空间地址
- group_id / area_no_group（json 数组）/ area_no：地块组合与地块编号
- user_id：拥有者 ID（→ tan_user.user_id，房东侧，待确认）
- building_resource_id / interior_resource_id / building_part_id / interior_part_id：建筑/内装配件资源编号（关联资源表，不在本库）

### tan_core_rent_order（租房订单表）

- 主键 order_id；**order_no（ZF+时间戳+随机）是房间表关联本表的真实键**
- group_part_id：楼栋 id（→ tan_core_group_part.id，已验证 98.1%）；asset_part_id：所用建筑资产 id（→ part_asset 表主键，该表不在本库）
- user_id：租户用户 id（→ tan_user.user_id，已验证 99.9%）；lessor_uid：房东
- r_start_time / r_end_time：租期开始/结束时间；rent_type：租房类型枚举见表注释（1=个人 2=商业）；**rent_period：租房周期，注释未标注枚举值，待确认**
- 金额（均为 decimal(20,4)，单位**元豆**）：rent_price 租房金额 / discount_price 优惠金额 / pay_price 实际支付金额 / profit_price 收益金额 / consume_price 参与分成金额；broken_brick 赠送碎金（**平台积分，非元豆**）
- coupon_id：优惠券 ID
- building_no / room_no / core_addr / area_no_group / area_no / group_id：楼栋/房间/地块信息冗余字段（便于无 JOIN 查询）
- **无 pay_status / order_status 字段**：订单支付与取消状态如何体现待确认，统计时暂以 deleted_at IS NULL 为有效订单口径
- app：消费平台（枚举值待确认）

### tan_core_rent_room（租房记录表）

- **status：当前房间状态以此为准**（1=租用中 2=冻结中 3=未租用，见表注释）
- user_id：租户用户 id（→ tan_user.user_id，已验证 99.8%）
- expire_time：过期时间（租约到期）；freeze_expire_time：冻结结束时间
- **order_no：关联的租房订单号（→ tan_core_rent_order.order_no，已验证 100%）。order_id 字段已废弃（数据全为 0），勿使用**
- rent_price / pay_price：租房价格 / 实际支付（元豆）；discount_price：优惠金额；coupon_id：优惠券 ID
- rent_type：租房类型枚举见表注释（1=个人 2=商业）；**rent_period：租房周期，注释未标注枚举值，待确认**
- level：等级；asset_part_id：所用建筑资产 id
- area_no_group / area_no / group_id：地块信息

## 4. 表关联关系

- 订单 → 楼栋：tan_core_rent_order.group_part_id = tan_core_group_part.id（多对一；约 2% 的楼栋 id 未命中，可能为已删除楼栋——group_part 有 deleted_at，JOIN 时注意）
- 房间 → 楼栋：tan_core_rent_room.group_part_id = tan_core_group_part.id（多对一，已验证 100%）
- 房间 → 订单：**tan_core_rent_room.order_no = tan_core_rent_order.order_no（多对一，已验证 100%）**；勿用 rent_room.order_id（已废弃，全 0）
- 租户 → 平台用户：rent_order.user_id / rent_room.user_id → tan_user.user_id（已验证 99.8%+）；core_group_part.user_id 为拥有者（房东）
- 一致性坑：group_part.rent_num（已出租数）为快照汇总字段，统计出租率建议实时 COUNT(rent_room.status=1)，两者可能不一致
- 一张订单可租多个房间（order_no 一对多），聚合时按 order_no 去重

## 5. 常用查询 SQL 示例

-- 各楼栋在租房间数（实时口径）
SELECT g.building_no,
       g.building_name,
       COUNT(r.id) AS renting_rooms
FROM tan_core_group_part g
JOIN tan_core_rent_room r
  ON r.group_part_id = g.id AND r.status = 1 AND r.deleted_at IS NULL
WHERE g.deleted_at IS NULL
GROUP BY g.building_no, g.building_name
ORDER BY renting_rooms DESC;

-- 租房收入按月（订单实际支付，元豆）
SELECT DATE_FORMAT(created_at, '%Y-%m') AS month,
       SUM(pay_price) AS rent_revenue
FROM tan_core_rent_order
WHERE deleted_at IS NULL
GROUP BY DATE_FORMAT(created_at, '%Y-%m')
ORDER BY month;

-- 租约即将到期预警（未来 30 天）
SELECT room_no, user_id, expire_time, order_no
FROM tan_core_rent_room
WHERE status = 1
  AND deleted_at IS NULL
  AND expire_time BETWEEN NOW() AND DATE_ADD(NOW(), INTERVAL 30 DAY)
ORDER BY expire_time;

-- 个人/商业租约分布（订单口径）
SELECT rent_type, COUNT(*) AS order_cnt
FROM tan_core_rent_order
WHERE deleted_at IS NULL
GROUP BY rent_type;

-- 楼栋出租率（实时口径，对比 rent_num 快照）
SELECT g.building_no,
       g.room_num,
       COUNT(r.id) AS renting_rooms,
       ROUND(COUNT(r.id) / NULLIF(g.room_num, 0), 4) AS rent_rate
FROM tan_core_group_part g
LEFT JOIN tan_core_rent_room r
  ON r.group_part_id = g.id AND r.status = 1 AND r.deleted_at IS NULL
WHERE g.deleted_at IS NULL
GROUP BY g.building_no, g.room_num;

## 6. 注意事项

- 数据更新频率：待确认（疑似准实时）
- **rent_order 无支付状态字段**：有效订单/退租口径待业务侧确认，目前暂以 deleted_at IS NULL 过滤
- **rent_num 是快照**：实时出租数以 rent_room.status=1 为准，勿直接信 rent_num
- **order_id 字段废弃**：房间表关联订单必须用 order_no（order_id 全 0）
- 房间状态机（推断，待确认）：未租用 → 租用中（下单）→ 冻结中（freeze_expire_time）→ 未租用/再出租；退租与续租流转以业务侧为准
- **金额单位**：rent_price / pay_price 等均为**元豆**，兑人民币 10:1（10 元豆 = 1 元人民币）；broken_brick（碎金）为平台积分，不可与元豆混算；金额字段 decimal(20,4)，展示注意 4 位小数精度
- 部分外键目标表不在本库（asset_part_id → part_asset 表），跨库查询需另走渠道
- 软删除惯例：三张表均带 deleted_at，统计时过滤 deleted_at IS NULL
